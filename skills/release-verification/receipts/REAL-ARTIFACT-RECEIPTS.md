# Real-artifact verification receipts

Generated by `skills/release-verification/receipts/regenerate.sh`. Do not hand-edit;
re-run the script instead. Artifact provenance (which build run each IPA came
from) is maintained by hand in SOURCES.md next to this file.

WHY THIS EXISTS. The documentation asserts real-artifact results -- "the shipped
build verifies clean" -- and nothing in a diff substantiates that. A reader can
check the synthetic tests, which prove the tool BEHAVES correctly, and then has to
take the shipped-build claims on trust. Assertion without checkable evidence is
exactly what this standard exists to eliminate, so the runs are recorded here and
each artifact is named by sha256 so the claim can be re-checked against the same
bytes.

WHAT THIS IS NOT. A receipt says what happened once. It does not replace
`tests/artifact-truth.test.mjs`, which runs in CI and pins what must KEEP being
true. IPAs are ~220 MB and expire from GitHub Actions after 14 days, so they are
not committed and cannot be linked; SOURCES.md is how you obtain the same ones.
